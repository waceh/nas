# 🛡️ AdGuard Home (LXC 102) 네트워크 광고 차단 및 내부 DNS 구축 가이드 (13)

> 💡 **본 문서는 Proxmox VE 상에서 Native LXC 102로 구동되는 초경량 네트워크 레벨 광고 차단기 및 로컬 DNS 서버(AdGuard Home)의 설치, 초기 셋업, 공유기 연동 및 내부 도메인(`nas.home`, `photo.home` 등) 설정 방법을 다룹니다.**

---

## 📌 1. AdGuard Home 개요 및 목적

* **컨테이너 ID**: `LXC 102` (Debian 12, 1 Core, 512MB RAM, 4GB SSD on `local-530`)
* **IP 주소**: `192.168.1.102`
* **초기 설정 포트**: `http://192.168.1.102:3000` (초기 셋업 완료 후 `:80` 또는 `:3000` 웹 콘솔)
* **DNS 포트**: `53` (UDP/TCP)
* **핵심 기능**:
  1. **네트워크 레벨 광고/트래커 원천 차단**: 스마트폰, 태블릿, 맥북, 스마트TV 등 집안 모든 기기에서 브라우저 확장 프로그램 없이 웹 광고 차단.
  2. **초고속 DNS 캐싱**: 자주 접속하는 도메인의 쿼리 응답 속도를 0ms대로 단축.
  3. **내부 로컬 DNS 도메인 매핑**: `192.168.1.107:3000` 대신 `http://nas.home` 같은 기억하기 쉬운 주소 사용.
  4. **초경량 리소스**: Go Native 단일 바이너리로 구동되어 **RAM 단 30~50MB**만 소모.

---

## 🚀 2. 원클릭 자동 설치 명령어

Proxmox VE 호스트 셸에서 아래 1줄 명령어를 실행합니다:

```bash
curl -fsSL https://raw.githubusercontent.com/waceh/nas/main/self-nas/scripts/setup_adguard_lxc.sh | bash
```

---

## ⚙️ 3. 초기 셋업 마법사 진행 가이드 (1분 컷)

1. 브라우저에서 [`http://192.168.1.102:3000`](http://192.168.1.102:3000) 접속 후 **[시작하기]** 클릭.
2. **네트워크 인터페이스 설정**:
   - **웹 관리 인터페이스**: `모든 인터페이스` / 포트 `80` (또는 `3000`)
   - **DNS 서버**: `모든 인터페이스` / 포트 `53`
3. **관리자 계정 생성**:
   - 사용자 이름 및 강력한 비밀번호 설정.
4. **[완료]** 클릭 후 로그인.

---

## 🌐 4. 집안 전체 기기 적용 방법 (공유기 연동)

집안의 모든 기기(스마트폰, 스마트TV 등)에 자동으로 광고 차단이 적용되도록 하려면 공유기 설정을 변경합니다:

1. **ASUS 공유기 관리 페이지** (`http://192.168.1.1`) 접속.
2. **[LAN] ➔ [DHCP 서버]** 메뉴 이동.
3. **DNS 및 WINS 서버 설정** 항목에서:
   - **DNS Server 1**: `192.168.1.102` (AdGuard Home IP)
   - **DNS Server 2**: `1.1.1.1` (보조 Cloudflare DNS - 비상용)
4. **[적용]** 클릭.
   - *이후 집안 Wi-Fi에 연결되는 모든 기기는 자동으로 광고가 차단됩니다!*

---

## 🏷️ 5. 예쁜 로컬 도메인 (DNS 변경 / Rewrite) 설정

복잡한 IP 번호 대신 예쁜 도메인을 붙여 쓸 수 있습니다:

1. AdGuard Home 관리자 페이지 ➔ **[필터링] ➔ [DNS 변경 (DNS rewrites)]** 클릭.
2. **`[DNS 변경 추가]`** 클릭:
   - **도메인**: `nas.home` ➔ **IP**: `192.168.1.107` (Homepage 대시보드)
   - **도메인**: `photo.home` ➔ **IP**: `192.168.1.103` (Immich)
   - **도메인**: `music.home` ➔ **IP**: `192.168.1.104` (Gonic)
   - **도메인**: `video.home` ➔ **IP**: `192.168.1.105` (Jellyfin)
   - **도메인**: `pve.home` ➔ **IP**: `192.168.1.200` (Proxmox VE)
   - **도메인**: `dsm.home` ➔ **IP**: `192.168.1.132` (Xpenology)
